# CRM для бизнеса по хранению шин

Это одностраничное CRM-приложение, созданное для управления клиентской базой, услугами и финансами в бизнесе по сезонному хранению шин.

## Функционал

- Аутентификация
- Дашборд с ключевыми метриками и графиками
- Управление клиентами (просмотр, поиск, фильтрация)
- Добавление новых клиентов
- Настройки приложения

---

## Развертывание на GitHub Pages

Этот проект настроен для **автоматического развертывания** с помощью GitHub Actions.

### Как это работает?

1.  Каждый раз, когда вы отправляете изменения в ветку `main`, GitHub Actions автоматически запускает процесс сборки.
2.  Проект собирается в статичные файлы (HTML, CSS, JS).
3.  Собранные файлы автоматически публикуются в специальную ветку `gh-pages`.

### Что нужно сделать для развертывания?

Вам нужно всего один раз указать GitHub, откуда брать опубликованный сайт.

1.  Перейдите в **"Settings"** (Настройки) вашего репозитория.
2.  В левом меню выберите **"Pages"** (Страницы).
3.  В секции **"Build and deployment"** (Сборка и развертывание), в выпадающем списке **"Source"** (Источник) выберите ветку **`gh-pages`**, а папку `/ (root)`.
4.  Нажмите **"Save"** (Сохранить).

После этого, при каждом пуше в `main`, ваш сайт будет автоматически обновляться. Ссылка на опубликованный сайт будет доступна в этом же разделе настроек Pages.
