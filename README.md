# CRM для бизнеса по хранению шин

Это одностраничное CRM-приложение, созданное для управления клиентской базой, услугами и финансами в бизнесе по сезонному хранению шин.

## Функционал

- Аутентификация
- Дашборд с ключевыми метриками и графиками
- Управление клиентами (просмотр, поиск, фильтрация)
- Добавление новых клиентов
- Настройки приложения

## Как развернуть на GitHub Pages (для новичков)

Это руководство поможет вам опубликовать ваш проект (сайт) в интернете. После этого у вас будет публичная ссылка, которой можно поделиться с кем угодно.

### Шаг 1: Убедитесь, что у вас есть `index.html`

GitHub Pages работает, находя файл `index.html` в корне вашего проекта. В этом проекте он уже есть.

### Шаг 2: Перейдите в настройки репозитория

1.  Откройте ваш репозиторий на сайте GitHub.
2.  Над списком файлов найдите и нажмите на вкладку **"Settings"** (Настройки).
    *Прямая ссылка (замените `USERNAME` и `REPO_NAME` на свои):* `https://github.com/USERNAME/REPO_NAME/settings`

### Шаг 3: Перейдите в раздел "Pages" (Страницы)

1.  В левом меню настроек найдите и нажмите на пункт **"Pages"** (Страницы).
    *Прямая ссылка:* `https://github.com/USERNAME/REPO_NAME/settings/pages`

### Шаг 4: Настройте источник развертывания

1.  Вы увидите секцию **"Build and deployment"** (Сборка и развертывание).
2.  В выпадающем списке **"Source"** (Источник) выберите **"Deploy from a branch"** (Развернуть из ветки).
3.  Ниже появится еще одна секция **"Branch"** (Ветка).
    *   В выпадающем списке **"Branch"** выберите ветку **`main`** или ту, в которой находится финальный код.
    *   Убедитесь, что в следующем выпадающем списке выбрана папка **`/ (root)`**.
4.  Нажмите кнопку **"Save"** (Сохранить).

### Шаг 5: Подождите и получите ссылку

1.  После сохранения GitHub начнет процесс развертывания. Это может занять несколько минут.
2.  Сверху страницы появится зеленая плашка с сообщением: **"Your site is live at..."** (Ваш сайт опубликован по адресу...).
3.  **Ваша ссылка готова!** Она будет выглядеть так: `https://USERNAME.github.io/REPO_NAME/`
